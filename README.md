# 家教助手

> **关于这个项目**
>
> 本项目由 **DeepSeek-V4.1-Flash 一句话生成，未经修改**。
>
> 所用提示词：
>
> > 我想创建一个小程序，功能是：家教单的导入（从微信群、或导入Excel表）、路线显示、家教的排课、日历显示。微信群中群主每次发的消息类似下面这种： ....
>
> 提示词后面跟了三条真实的群消息样例（通州大学生单 / BJ26062502 / H0032026），解析引擎就是照着它们写的。
>
> 仓库初始化（`git init`）和 `appid` 配置是后续补做的，不涉及业务代码改动。

![页面总览](docs/images/preview-all.jpg)

家教单从微信群里一条条复制、再手工整理到表格里，费时又容易漏。这个小程序把这件事变成：**粘贴 → 自动拆成结构化单子 → 排课 → 日历 → 跑单路线**。

uni-app + Vue3 + TypeScript，一套代码出微信小程序和 H5；数据默认存本机，可选接入腾讯云开发做多端同步。

---

## 功能

| 模块 | 说明 |
| --- | --- |
| 家教单导入 | ① 粘贴群消息，自动按「＃标题 / 单号 / 【北京线下】」切分；② 导入 Excel/CSV，表头自动映射 |
| 家教单管理 | 列表筛选（状态 / 区域 / 关键词）、详情、手动补录、状态流转 |
| 排课 | 按「每周几 + 时间 + 生效区间」建档期，自动展开成每次课 |
| 日历 | 月历视图，每天用色点标记课程，点开看当天安排、勾完成 |
| 路线 | 当天课表按时间排序 → 地图打点 → 每段里程/耗时 → 一键导航；另附「区域分布」聚合视图 |
| 设置 | 云同步、位置服务 Key、默认值、数据导入导出 |

## 快速开始

```bash
pnpm install
pnpm dev:h5          # 浏览器打开 http://127.0.0.1:5178
```

首次进入会自动灌入 8 条示例家教单 + 4 个排课档期，日历和路线一进去就有内容。想清空：设置 → 清空所有数据。

跑测试（解析引擎）：

```bash
pnpm test
```

出小程序包：

```bash
pnpm build:mp-weixin
# 然后用微信开发者工具打开 dist/build/mp-weixin
```

> `appid` 已填在 `src/manifest.json` 的 `mp-weixin.appid`，换项目时改这一处即可，构建产物会自动带出。

## 解析引擎：它到底能认哪些写法

群里的消息格式非常随意，解析器做了三层处理：

**1. 切分**——一条新单的开始标记有三种，只要当前块里已经有字段行，就切一刀：

```
＃通州大学生单          ← # 开头的短标题
北京线下gy26072504      ← 带单号的行
【北京线下】H0032026    ← 【X】里不是字段名
```

「＃通州大学生单」和紧接着的「北京线下gy26072504」会被正确归到同一单，不会被切碎。

**2. 字段归一**——`【标签】值` 和 `标签：值` 都支持，标签走同义词表 + 关键词兜底：

| 目标字段 | 能识别的写法 |
| --- | --- |
| 地址 | 辅导地点 / 补课地址 / 上课地址 / 地点 / 地址 / 住址 … |
| 课时费 | 课时报酬 / 课费报酬 / 课时价格 / 课时费 / 课酬 / 薪资 … |
| 频次 | 时间次数 / 一周几次 / 上课频率 / 每周次数 … |
| 年级科目 | 年级科目 / 学生年级 / 补习科目 / 科目 … |

**3. 值解析**——这些都能拆出来：

- `150-180/h` → 价格区间 150~180，单位 元/小时
- `100/小时（一次课1.5-2小时）` → 价格 100，时长 90 分钟（不会被括号里的 1.5 带偏）
- `一周2-3次` → 每周 2~3 次
- `暑假一周3次，每次2h` → 每周 3 次，单次 120 分钟
- `新高二` → 高二；`新4年级` → 四年级
- `#==通州宋庄==` → 通州宋庄（去掉强调符号）
- `男体育生擅长跑步` → 老师性别 男；科目 体育·跑步
- `BJ26062502` / `gy26072504` / `H0032026` → 单号

解析不出来的关键字段会记进 `missing`，列表和详情页会用橙色标签提示「缺年级 / 缺地址」，方便补录。

想加新写法，改 `src/parser/dict.ts` 里的 `FIELD_SYNONYMS` 就行；改完跑 `pnpm test`，`tests/parser.test.ts` 里是真实样例回归。

## Excel 导入

- 支持 `.xlsx` `.xls` `.csv`
- 第一行是表头，列名直接用「年级 / 科目 / 辅导地点 / 课时报酬 / 时间次数」这类写法，**顺序不限**，多余列自动忽略
- 实现上，每一行会被拼成「【表头】值」的伪消息，再喂给同一个解析器——所以表格和群消息的识别结果完全一致，不会出现两套规则打架
- 导入页有「下载模板」按钮

## 路线与地图

两条路都通：

**不配置 Key（默认）**
- 地图用示意图：按经纬度比例打点、连线、标序号，网格底图
- 坐标用内置片区坐标表估算（通州北苑/杨庄/宋庄/果园/梨园… + 城六区常见商圈），叠加固定抖动避免重叠
- 里程和耗时按直线距离 × 1.35 绕行系数、25km/h 城区均速估算

**配置腾讯位置服务 Key 后**
- 真实地理编码 + 驾车路线规划，地图画出实际道路
- 小程序端用原生 `<map>` 组件，标记和路线都是真的
- 申请：<https://lbs.qq.com/dev/console/application/mine>，然后把 Key 填到「设置 → 腾讯位置服务 Key」
- 小程序还需在小程序后台把 `https://apis.map.qq.com` 加入 request 合法域名

一键导航：小程序走 `uni.openLocation` 打开微信内置地图，H5 走高德 URI。

## 云同步（可选）

不配也能用，数据存在本机 `uni.setStorageSync`。要开多端同步：

1. 复制 `.env.example` 为 `.env`，填 `VITE_ENV_ID` 和 `VITE_PUBLISHABLE_KEY`
2. 在云开发控制台建两个集合：`tutor_orders`、`tutor_courses`
3. 两个集合的权限都设为「仅创建者可读写」
4. App 里「设置 → 云端同步」打开开关，点「立即同步」

登录策略：小程序端走 OpenID 静默登录（身份稳定），H5 端走匿名登录。

> ⚠️ 前端只能放 Publishable Key。SecretId / SecretKey 绝对不能打进前端包。

## 已知边界

- 单次粘贴建议不超过 200 条，太多会拖慢首屏渲染
- 片区坐标是估算值，同一片区的单子位置会略偏，配了 Key 才准
- 解析器只处理中文家教单的常见写法，遇到完全自由格式的叙述会退化成「原文 + 少量字段」
